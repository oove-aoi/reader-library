12/18
BookRepository 修改 public Optional<Book> findWithDetailById(Long id);
BookRepository search方法不可使用
因為 data jpa預設 -> 繼承JpaRepository 、宣告一個沒有@Query且沒有自訂實作的方法
會認為Query Method（方法名稱查詢）

要解決就是要自訂 Repository + 實作類（標準做法）
重點大概包含
1.BookRepository 繼承 自訂 Repository
2.實作類命名規範為 BookRepository + "Impl" -> 極為重要 儲存庫名+Impl不能錯
3.實作類要寫JPQL、實戰技巧上有查詢時的條件會用先加上WHERE 1=1
這樣後面的條件判斷就能減少很多不必要的麻煩
JPQL跟SQL很像，差別在於操作jpa的實體
所以 表名 -> 實體、欄位名 -> 屬性名、Join 是「物件路徑」，不是條件

八、我給你一個「學 JPQL 的最佳方式」
不要背語法，請照這個流程：

1.先用 SQL 想清楚你要什麼
2.問自己：「這張表在 Entity 裡是什麼？」
3.把欄位換成「物件屬性」
4.把 join 換成「關聯路徑」

@InjectMocks 建立"真實" service 物件
[會把 @Mock 的依賴注入到 service 的 constructor / field / setter 裡
